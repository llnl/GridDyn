# WECC approved dynamic model coverage (September 2026)

- **Catalog:** [WECC Approved Dynamic Model Library, September 2026](https://www.wecc.org/sites/default/files/documents/progress_report/2026/Approved%20Dynamic%20Models%20Sept%202026.pdf)
- **Effective date:** 2026-09-18
- **GridDyn source review:** 2026-10-10

This crosswalk compares the catalog's GE PSLF model names and listed PSS/E / PowerWorld aliases with GridDyn's native model registrations and its PSS/E DYR and PSLF DYD import dispatch. It replaces the earlier article-based inventory in this file with the WECC catalog as the approval-status source.

## How to read the assessment

- **Supported** means GridDyn has a named native implementation and accepts the catalog's applicable GE PSLF and PSS/E record spellings through DYD and DYR, respectively. PowerWorld-only aliases are not import formats.
- **Partial** means a native model or one of its import paths exists, but a listed record spelling, alternate format, signal, parameter mode, or measurement feature is missing.
- **Gap** means no exact model-specific implementation and applicable import path were found. Generic components and related models are not counted as substitutes.
- These labels assess implementation and import coverage. They do not claim WECC certification, complete parameter-range coverage, or trajectory parity with PSLF, PSS/E, or PowerWorld.
- The table's PSLF, PSS/E, and PowerWorld names can identify distinct variants. A shared IEEE label or similar name alone does not make two entries equivalent. PowerWorld-only entries also have no GridDyn DYR/DYD import path unless stated.
- DYR and DYD coverage are format-specific: a PSS/E DYR path does not imply the PSLF model spelling will import.

The catalog's color notes are source metadata: green marks its preferred variant for submission, and yellow marks models not converted from PSLF to PSS/E. This crosswalk includes every approved entry, not only green rows; color is not a GridDyn support label.

Only catalog entries marked approved (including entries whose comments describe them as approved despite a blank status cell) are in the target. Retired, unapproved, never-approved, pending, or removed entries are excluded and called out where they affect interpretation. Duplicate catalog rows such as PSS2C are listed once.

## Summary

Coverage is strongest for a subset of conventional machine controls, the first-generation renewable stack, and a restricted PSS/E composite-load path. The largest gaps are WECC's newer grid-forming and plant-control models, the expanded approved governor and excitation families, protection / FACTS models, and several models approved in 2025-2026.

A model being present in the source tree does not by itself mean GridDyn accepts the WECC catalog's record. The status below accounts for importer mappings as well as named native implementations.
