GridDyn command-line quick reference

Usage
  gridDynMain [options] input
  gridDynMain --input network.xml --script study.gds
  gridDynMain network.xml -P "action=powerflow; get time; save powerflow results.csv"

Use gridDynMain --help for the options and aliases available in your build.
See command-interface.md for the action language and a runnable two-bus study.

Input and control
  -h, -?, --help                Show command-line help
  --version                     Show the version
  --config-file FILE            Read an INI configuration file
  --input FILE                  Load the primary case, also accepted as a positional argument
  -i, --import FILE             Import an additional case file after the primary case
  -P, --param NAME=VALUE        Override a simulation parameter
  -P "action=COMMANDS"          Queue commands after XML actions
  --script FILE                 Queue a script after XML and --param actions
  --event DESCRIPTION           Schedule an event after loading the case
  -f, --flags FLAGS             Set simulation flags
  --powerflow-only              Use the power-flow-only simulation mode
  --optimization                Load an optimization simulation for DC OPF
  -j, --threads N               Set worker count in a multithreaded build

Case readers
  --dir DIRECTORY               Add an input search directory
  --file-flags FLAGS            Set reader flags
  -D, --define NAME=VALUE        Define a substitution for element readers
  -T, --translate NAME=VALUE     Define a translation for element readers
  --match-type MODE             Set parameter name matching to strict, exact, capital,
                               caps, any, or all

Results and diagnostics
  -o, --powerflow-output FILE   Write solved results
                               Use .raw, .m, or .py to export a network case
  --power_flow_input_data FILE  Write the initial power-flow data before solving
  --state-output FILE            Write the final state
  --save-state-period N          Set state save period in milliseconds
                               Requires --state-output. A value of -1 saves only at the end
  --jac_state FILE               Save power-flow Jacobian data
  --log-file FILE                Write a log file
  -v, --verbose                 Set verbose output (3)
  --printlevel LEVEL            Choose none (0), summary (1), normal (2), or verbose (3)
  --summary                     Set summary output (1)
  -q, --quiet                   Suppress regular output (0)
  -w, --warn, --warn-important  Show important warnings (1)
  --warn-all                    Show all warnings (2)
  --no-warn                     Suppress warnings (0)
  --auto-capture-period SECONDS Set the automatic recorder's sample interval
  --auto-capture FILE           Configure automatic recorder output
  --auto-capture-field FIELD    Add a field to the automatic recorder
                               Capture files and fields require --auto-capture-period

The executable initializes the case before draining its action queue. It runs
XML actions first, then --param actions, then --script files in the order given.
Commands stop at the first error, and the process exits with a nonzero status.
